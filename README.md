# Weldman

Custom WordPress theme for [weldman.ee](https://weldman.ee) — a welding
training center in Tallinn, Estonia.

The theme lives in [`weldman-theme/`](weldman-theme/) — see
[`weldman-theme/README.md`](weldman-theme/README.md) for the stack, folder
structure, required plugins (ACF, Polylang, optionally Contact Form 7 and a
caching plugin), the ACF field groups it registers, and the recommended
order of work for migrating content off the current Elementor-based site.
